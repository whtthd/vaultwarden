# 密码库增强功能使用指南

本文说明增强版网页密码库的操作方法和权限边界。开发环境搭建见
[DEVELOPMENT.md](DEVELOPMENT.md)，版本限制、接口和自动化测试见
[WEB_VAULT_ENHANCEMENTS.md](WEB_VAULT_ENHANCEMENTS.md)。

## 1. 使用前准备

- 网页端与后端需要同时更新；不要只替换网页文件而继续使用旧后端。
- 当前仅适配上游 web-vault **2026.10.1**。在仓库根目录运行
  `python3 tools/prepare_web_vault.py` 安装增强功能，然后重新加载网页。
  本机调试可使用 `bash tools/dev.sh web` 或 `bash tools/dev.sh run --offline`。
- 准备工具会核对原始文件及每个修改位置。不支持的版本会停止处理；升级
  web-vault 时需要重新适配，不能跳过检查或手工套用旧补丁。
- 权限测试请使用独立数据库、虚构账号和测试登录项，不要使用真实密码。
  本机测试数据、账号、证书、截图和走查记录均不应进入代码仓库。

## 2. 浏览与筛选

- 密码库左侧集合树与右侧结果列表可分别滚动。左侧的“筛选”标题和搜索框会固定
  在左栏顶部，滚动集合树时仍可直接搜索。选择集合时右侧列表会回到顶部，左侧
  保留当前位置。
- 在搜索框输入文字仍会正常筛选。切换集合、文件夹、组织或项目类型时，
  会清除上一条文字搜索，避免新位置继续被旧条件筛成空白。
- 从搜索结果进入某个集合也会清除旧搜索。如需在新集合内搜索，请重新输入。
- 选中集合后输入有效搜索词，会同时搜索当前集合及所有层级子集合中**当前账号有权
  访问的项目**，无需逐个打开子集合。清空搜索或搜索词尚未达到现有搜索规则时，
  恢复原有的逐级浏览，不会将全部下级项目平铺。
- 搜索不会授予额外权限：父集合可见不等于子集合项目可见，只有子集合权限时，
  也可从显示的上级结构节点搜索已授权下级，但不会返回无权访问的父集合项目。
  同级、相似前缀和其他组织的集合不会混入；类型、收藏、文件夹、回收站等原有
  筛选条件仍然生效。一个项目属于多个匹配集合时不会因此重复显示。
- 权限或集合结构同步变化后会重新计算搜索范围。集合已不可见、结构节点已消失时，
  不会退回全库搜索。离线客户端仍须先同步；本功能不能收回已经解密或复制的秘密。

## 3. Admin Console 长列表与组织密码库搜索

- 组织密码库沿用个人密码库的双栏布局：左侧集合树和右侧项目列表分别滚动，
  “筛选”标题、搜索框和组织密码库中的筛选控件会固定在左栏顶部。右侧使用独立
  的虚拟列表滚动，长列表不会再把筛选区和项目列表一起带走。
- 在组织密码库选择父集合后输入搜索词，会包含该父集合及其所有层级子集合中
  当前账号已获得的项目。管理员目录中的集合名称只用于计算路径，不能凭空增加
  项目权限；没有出现在当前授权项目快照中的登录项不会被返回。切换集合、组织或
  其他筛选条件时，旧搜索会清空，需要在新范围重新输入。
- 成员和群组页面的搜索框、成员状态筛选和长列表互不争夺页面滚动。滚动表格时，
  搜索与状态控件保持可见，虚拟列表继续使用原有页面滚动容器。切换组织或成员
  状态时会清除旧搜索，输入新搜索时列表回到顶部；进入新管理页面时使用该页面
  自己的搜索条件，不会影响从事件日志等入口带来的明确搜索链接。
- 目前检查到的其他带搜索和虚拟长列表的 Admin Console 页面也使用同一套处理。
  普通设置页和没有长列表的页面保持原有滚动行为。

## 4. 批量调整子集合权限

打开目标集合的菜单，进入“访问权限”或编辑窗口中的“编辑访问权限”页。
有子集合时，会显示“同时应用到子集合”区域。

### 选择本次操作范围

| 操作 | 作用 |
| --- | --- |
| 勾选某一行 | 只选择该集合，不自动包含它的下级。 |
| 全选此分支 | 选择该分支本身及其可管理的全部下级。 |
| 取消此分支 | 一次清除该分支的选择，不影响其他分支。 |
| 全选子集合 / 取消选择 | 同一个按钮切换全选与清除。已有部分选择时，点击即清除。 |

**勾选表示“本次修改应用到哪些子集合”，不是已有权限的开关。**
取消勾选只会缩小本次操作范围，不会撤销之前保存的授权。重新打开窗口时，
范围从零开始选择，这不代表成员已经失去权限。无管理权限的节点不可勾选。

### 新增或修改授权

1. 勾选需要一起调整的子集合，或使用分支、全选按钮。
2. 在下方成员／群组权限表中新增成员、调整权限或移除授权。
3. 检查范围和权限，点击窗口底部的“保存”。

保存会修改当前父集合，并将**这次发生变化的成员／群组授权**同步到所选子集合。
子集合中其他成员和群组的独立授权会保留，未选分支不变。

仅勾选子集合而不修改权限表，不会把父集合原有授权复制过去。
如某成员在父集合中原本已有授权，而只需为部分子集合新增该授权，应直接编辑
相应子集合；不要通过临时降低父集合权限来触发批量变更。

### 同时撤销父集合与子集合授权

在父集合权限表中移除目标成员／群组，勾选需要回收权限的子集合，然后保存一次。
只移除父集合授权而没有勾选子集合时，子集合原有的直接授权会保留。

### 仅撤销子集合授权

父集合之前已经移除该成员，或希望保留父集合授权时，无需先重新授权再移除：

1. 勾选需要撤销授权的子集合。
2. 在“仅撤销所选子集合授权”中，从“要撤销的成员或群组”选择目标。
   列表来自所选子集合的直接授权。
3. 点击“安排撤销”，可继续安排其他成员或群组。
4. 点击窗口底部的“保存”，一次完成。

此操作不改变父集合、未勾选分支或其他成员的授权。“取消此次撤销”可移除一项
待办；窗口底部“取消”会放弃整次未保存操作。安排撤销后若清空范围，保存会被
阻止；重新选择范围即可继续，不必重新安排。撤销最终作用于**保存时勾选的范围**。
保存期间范围控件会暂时禁用，避免中途变化。

### 权限边界与同步

- 父子关系是名称路径结构，不代表权限自动继承。授权给父集合不会自动开放子集合。
- 只有子集合权限时，仍可看到完整上级结构。上级仅是导航节点，不授予其中项目的
  访问权，也不能作为真实集合进行编辑或删除。
- 批量保存会核对每个集合的管理权限及成员／群组的组织归属，并在同一事务中写入；
  任一目标不合法时，整次失败，不会只保存一部分。
- 权限是叠加的。撤销一处授权后，成员仍可能通过群组、组织级权限、其他集合或
  单项授权访问同一登录项。此时应检查所有授权来源，而不是反复点击取消。
- 保存成功后会通知在线成员同步，无需重新登录；断线或离线客户端需要重连同步。
  已经解密、复制或导出的秘密无法收回，敏感密码泄露时仍需在目标服务中轮换密码。

## 5. 从成员页面管理集合权限

在管理控制台进入“成员”，点击成员名称，再切换到“集合”页。这里会按完整路径
显示集合层级，而不是将所有集合放进一个平铺下拉框。

1. 展开所需分支，或搜索名称／完整路径。缺失的上级只显示结构，不会被保存为
   新集合；同名集合仍按各自 ID 区分。
2. 可勾选多个集合，或点击“全选分支”。行上的复选框只选择当前集合，
   分支按钮则包含该分支及下级；部分选择时也可一次“取消分支”。
3. 选择“批量权限”后点击“应用到所选集合”，或点击“移除所选直接授权”。
   也可在某一行的“直接权限”下拉框单独修改，选择“未直接授权”移除该项。
4. 检查结果，最后点击窗口底部“保存”，才会实际更新该成员权限。

注意事项：

- 勾选框仍是本次批量操作范围，**不是已授权状态**。已有直接权限显示在每一行的
  权限栏。取消选择不会撤销已应用到表单的变更；关闭窗口可放弃所有未保存修改。
- 可使用“折叠全部／展开全部”快速浏览。搜索结果保留完整上级结构，但批量操作
  只覆盖匹配项，不包含仅作为上下文的父集合。改变搜索会清空批量范围，避免将
  看不见的旧选择一起授权；已应用到表单的权限变更仍保留。
- 群组授权会标明来源，只读集合不能参与批量写入。移除直接授权不会修改群组成员
  关系，也不会降低已有组织级、群组或其他来源的权限。
- 父级和子级的直接权限可以分别设置；不会因为勾选父级就自动修改未选中的子级。
  保存使用原成员编辑流程，不会修改其他成员或登录项的集合归属。

## 6. 集合改名与移动

在集合编辑窗口修改名称或上级集合并保存，系统会同步更新全部子集合的路径前缀。
集合 ID、登录项关联、外部 ID 和各自独立权限保持不变，不会新建一个同名集合
来替代原集合。即使未勾选权限范围，结构调整仍会覆盖完整子树。

注意事项：

- 操作者必须能查看组织全部集合，并拥有所有受影响集合的修改权限；无法确认
  隐藏子集合时，请交由具备完整可见性和相应权限的管理员操作。
- 不能移动到自己的子集合内；目标路径冲突、原路径存在歧义或有子集合不可编辑时，
  整次保存会被阻止。已有重复集合不会自动合并。
- 新建／改名时不允许空白路径段或新末级名称首尾空格；同一路径下会检查重名。
  不同父级或不同组织可以使用相同末级名称。旧有异常名称仍可单独修改权限。
- 重名比较会忽略各级首尾空白并统一 Unicode 表示，但不会改写旧名称。
  名称经过加密，检查仅覆盖当前可见集合，不能保证隐藏集合、并发操作或导入的
  全局唯一性。
- 自动保留子树是本增强网页端的功能；其他 Bitwarden 客户端不会自动获得该行为。
  需要调整层级时请使用本网页端。

## 7. 单独为一个登录项分配权限

适用于**组织所有者或管理员**为某个组织登录项单独授权，不需要把整个业务集合
开放给成员。个人密码库项目、非登录类型、已删除项目及不完整列表行不提供此入口。

1. 在密码库结果列表找到组织内的登录项，点击该行的“单项权限”。
2. 搜索并勾选成员。新增授权需要成员已接受邀请并被组织确认；所有者、管理员
   和组织全量访问成员已有的权限不在此处降低。
3. 为每位成员选择“查看项目”“查看项目，隐藏密码”“编辑项目”或
   “编辑项目，隐藏密码”。
4. 点击“保存单项权限”，成功后点击“完成”。撤销时重新打开，取消勾选该成员
   后保存。未保存前点击“取消”不会写入。

注意事项：

- 单项授权只增加该登录项的访问权，不开放原集合中的其他项目，不改变原集合归属。
  此窗口不提供群组授权或“管理集合”权限。
- 撤销单项授权不等于彻底禁止访问；已有组织、集合或群组授权仍然有效。
- “隐藏密码”沿用客户端现有权限模型，不是收回已分发秘密的加密隔离措施。
  不要把它当作防止已获密钥的客户端提取秘密的安全边界。
- 系统使用“单项授权”路径下的专用集合兼容现有客户端。该集合仅绑定一个登录项，
  请通过“单项权限”窗口管理，不要将其改作普通集合或放入其他项目。普通集合修改、
  批量权限接口和导入不能将它改作其他用途，克隆登录项也不会继承原项的专用集合。
- 从未授权的项目在空选择下保存，不会创建空集合；已经创建的专用集合在撤销全部
  成员后可能继续存在。这不代表仍保留直接成员授权。
- 如果提示“权限已保存，请刷新页面同步本机缓存”，说明服务端已经保存，按提示
  刷新即可，不要把它当作保存失败而重复提交。

## 8. 本机调试与回退

本机调试使用 `https://127.0.0.1:8001`，不要切换到 8000 或 HTTP。
`bash tools/dev.sh web` 还会在 HTTPS 回环地址的 8001 端口开放现有的 `Never`
会话超时选项。应用后需重新加载、解锁，再到“设置 → 安全 → 会话超时”中
手动选择 `Never` 并确认。

此设置按账号和浏览器保存，会话密钥在当前标签页会话中保留，刷新后可继续解锁；
关闭浏览器会话后可能需要再次解锁。它仅用于受控本机调试，不应作为生产环境关闭
超时保护的方案。其他账号、浏览器或配置文件需要分别设置。

需要恢复原始网页端时，在仓库根目录执行并重新加载：

```bash
python3 tools/prepare_web_vault.py --restore
# 本机调试也可使用：
bash tools/dev.sh web --restore
```

恢复只切回原始网页资源，不撤销已保存的集合结构、权限或单项授权数据。
下次运行 `bash tools/dev.sh run` 会重新应用增强。恢复原始网页端后，也应在
设置中检查会话超时；工具不会自动重置之前选择的 `Never`。
